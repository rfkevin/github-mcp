# Projet d’essai du MCP

Ce projet utilise les modules JavaScript de Node, sans dépendance externe.
La commande de vérification est npm test ; aucune installation n’est nécessaire.

Lire les fichiers avant de modifier le code. Ajouter des tests pour les nouveaux
comportements. Créer la branche de travail depuis la branche demandée, conserver
le SHA de base et ouvrir une PR en brouillon vers cette même branche.

Si le plan de vérification est absent, préparer un plan version 1, install vide,
avec quick et unit exécutant npm test. Prévisualiser puis appliquer le workflow
encadré avec github_prepare_checks. Suivre le run du commit exact. Un profil
réussi ne prouve pas l’existence d’autres tests.
